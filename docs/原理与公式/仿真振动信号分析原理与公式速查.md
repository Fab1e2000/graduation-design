## 1. 齿轮运动学与特征频率

| 物理量 | 公式 | 本仿真数值（30 Hz 工况） |
| :--- | :--- | :--- |
| 输入轴转频 $f_{\text{in}}$ | $f_{\text{in}} = n_1 / 60$ | $1800 / 60 = \mathbf{30.00\text{ Hz}}$ |

## 2. 仿真动力学与测点响应原理

### 2.1 质量对加速度幅值的影响（RP1 > RP2）
主动轮与从动轮齿面承受大小相等的啮合力 $F$，由牛顿第二定律：
$$a = \frac{F}{m}$$
小齿轮（`SS1.5-29`）质量远小于大齿轮（`SS1.5-95`），因此输入轴 `RP1` 的加速度幅值约为中间轴 `RP2` 的 **5 倍**。

### 2.2 切向与径向振动差异（Y 向 > X 向）
标准直齿轮压力角 $\alpha = 20^\circ$，齿面切向力 $F_t$（Y 向，`A2`）与径向分离力 $F_r$（X 向，`A1`）之比为：
$$\frac{F_t}{F_r} = \cot\alpha = \cot 20^\circ \approx 2.75$$
因此 **Y 向（`A2`）是啮合主受力方向**，振动幅值约为 X 向（`A1`）的 2.3 倍，对啮合与故障最敏感。

### 2.3 为什么高阶啮合谐波（$2f_{m1}, 4f_{m1}$）常高于 $1f_{m1}$？
1. **加速度的 $\omega^2$ 放大效应**：位移 $x(t) = X\sin(\omega t)$ 求两次导数得加速度 $a(t) = -\omega^2 X\sin(\omega t)$，频率翻倍则加速度天然放大 $2^2 = 4$ 倍，4 倍频放大 16 倍。
2. **结构固有频率共振**：弹性轴承支承下的齿轮系统存在固有频率 $f_n = \dfrac{1}{2\pi}\sqrt{\dfrac{k}{m}}$，落在固有频率共振区附近的啮合倍频会被显著放大（如 `RP2` 放大 $2f_{m1}=1740\text{ Hz}$，质量更轻的 `RP1` 放大 $4f_{m1}=3480\text{ Hz}$）。
3. **重合度刚度脉冲**：$\varepsilon_\alpha = 1.746$ 使单/双齿交替刚度呈“75% 宽 / 25% 窄”脉冲，本身富含较强的偶次谐波。

## 3. 仿真信号预处理规范

1. **单位统一**：Abaqus 采用 `mm-tonne-s-N-MPa` 单位制，导出加速度为 $\text{mm/s}^2$，需除以 $1000$ 换算为标准单位 $\text{m/s}^2$。
2. **剔除启动瞬态**：前 `0 ~ 0.05 s` 包含 Smooth Step 升速冲击，仅截取稳态段 `0.05 ~ 0.50 s` 分析。
3. **等间隔重采样**：文本导出时间存在有效数字截断抖动（`78 ~ 79 μs`），做频谱前需线性插值重采样至严格等间隔 $f_s = 12800\text{ Hz}$（$\Delta t = 78.125\ \mu\text{s}$）。
4. **去直流偏置**：$x_0[n] = x[n] - \bar{x}$，消除零漂对 0 Hz 频谱与 RMS 的干扰。

## 4. 时域特征指标（健康基线与冲击监测）

设去均值后的稳态离散加速度序列为 $x_1, x_2, \dots, x_N$：

### 4.1 有量纲指标（反映振动整体强弱，单位 $\text{m/s}^2$）
- **有效值（RMS）**：$X_{\text{rms}} = \sqrt{\dfrac{1}{N}\sum_{i=1}^{N} x_i^2}$
- **峰值（Peak）**：$X_p = \max_i |x_i|$
- **峰峰值（Peak-to-Peak）**：$X_{p\text{-}p} = \max_i x_i - \min_i x_i$

### 4.2 无量纲指标（反映冲击尖锐度，不受幅值缩放影响）
- **峭度（Kurtosis）**：
  $$K = \frac{\dfrac{1}{N}\sum_{i=1}^{N} x_i^4}{\left(\dfrac{1}{N}\sum_{i=1}^{N} x_i^2\right)^2}$$
  健康平稳振动近似服从正态分布，$K \approx 3.0$；出现缺齿等周期性冲击时 $K$ 会显著升高。
- **峰值因子（Crest Factor）**：$C_f = \dfrac{X_p}{X_{\text{rms}}}$
- **脉冲因子（Impulse Factor）**：$I_f = \dfrac{X_p}{\dfrac{1}{N}\sum_{i=1}^{N} |x_i|}$

## 5. 频域分析、调制与边频带原理

### 5.1 加窗单边幅值谱（FFT）
对稳态信号加汉宁窗 $w[n]$ 以抑制频谱泄漏，单边幅值谱为：
$$A(f_k) = \frac{2}{\sum_{n=0}^{N-1} w[n]} \left| \sum_{n=0}^{N-1} x_0[n]\,w[n]\,e^{-j 2\pi k n / N} \right|$$
稳态时长 $T = 0.45\text{ s}$ 时，频率分辨率 $\Delta f = 1 / T \approx 2.22\text{ Hz}$。

### 5.2 为什么会出现“相乘（包络调制）”而非简单相加？
由齿面接触胡克定律 $F(t) = k(t)\cdot x(t)$：
- 啮合刚度按高频载波 $\omega_c = 2\pi f_c$（啮合频率）变化：$k(t) = k_0 + k_1\cos(\omega_c t)$；
- 弹性支承晃动或单齿缺失使齿面压紧量按低频 $\omega_m = 2\pi f_m$ 变化：$x(t) = x_0 + x_1\cos(\omega_m t)$。

两者相乘展开后，必然产生交叉调制项 $\cos(\omega_c t)\cos(\omega_m t)$。

### 5.3 幅值调制（AM）与相位/频率调制（FM）的边频带推导
记高频载波角频率 $\omega_c = 2\pi f_c$，低频调制角频率 $\omega_m = 2\pi f_m$（系数写为 $2A, 2B$ 仅用于约去积化和差中的 $\frac{1}{2}$）：

1. **幅值调制（AM，受力忽大忽小）**：
   $$\big(1 + 2A\cos(\omega_m t)\big)\cos(\omega_c t) = \cos(\omega_c t) + A\cos\big((\omega_c - \omega_m)t\big) + A\cos\big((\omega_c + \omega_m)t\big)$$
   `cos × cos` 拆出左右**同号**边频（$+A, +A$）。

2. **相位/频率调制（FM，瞬时转速忽快忽慢）**：
   当相位抖动 $2B \ll 1$ 时，由和角公式近似展开：
   $$\cos\big(\omega_c t + 2B\sin(\omega_m t)\big) \approx \cos(\omega_c t) - 2B\sin(\omega_c t)\sin(\omega_m t)$$
   其中 `sin × sin` 积化和差拆出左右**异号**边频（一正一负）：
   $$2B\sin(\omega_c t)\sin(\omega_m t) = +B\cos\big((\omega_c - \omega_m)t\big) - B\cos\big((\omega_c + \omega_m)t\big)$$

3. **左右边频不对称的成因**：
   真实齿轮箱中 AM 与 FM 同时存在，合并同类项后一侧边频同号增强（$A+B$），另一侧异号抵消（$A-B$），再加上结构频响对不同频率的放大差异，因此频谱中左右边频通常一高一矮。

### 5.4 本仿真中两类边频带的区分
- **系统低阶固有晃动边频（健康即存在）**：间距宽，位于 $n f_{m1} \pm 251\text{ Hz}$（如 `1740 ± 251 Hz` → `1489 / 1991 Hz`）。
- **单齿缺失故障边频（故障特征）**：紧贴啮合频率两侧，呈一排等距分布 $n f_{m1} \pm k f_{\text{mid}}$（即 $\pm 9.16, \pm 18.32, \pm 27.47\text{ Hz}\dots$），健康状态下几乎平贴底噪。
