## 2. 齿轮箱核心物理参数

### 二级定轴齿轮箱（当前重点）
- **三轴空间布置**：三角形布置 — **输入轴（右下）**、**中间轴（上方）**、**输出轴（左下）**；两级齿轮副分置前后两平面。
- **齿轮参数**（标准直齿，模数 $m = 1.5\text{ mm}$，压力角 $20^\circ$，参考齿宽 $15\text{ mm}$）：
  - **第一级**：输入轴 `SS1.5-29` ($d=43.5\text{ mm}$) ↔ 中间轴 `SS1.5-95` ($d=142.5\text{ mm}$)，$i_1 = 3.276$，$a_1 = 93.0\text{ mm}$
  - **第二级**：中间轴 `SS1.5-36` ($d=54.0\text{ mm}$) ↔ 输出轴 `SS1.5-90` ($d=135.0\text{ mm}$)，$i_2 = 2.500$，$a_2 = 94.5\text{ mm}$
  - **总传动比**：$i_{\text{总}} = 475/58 \approx \mathbf{8.190}$（减速；输入与输出同向，中间轴反向）
- **支撑轴承**：3 轴两端共 6 套 **MB ER-16K**（轴径 1" / $25.4\text{ mm}$，滚动体 $N=9$）
  - 故障特征阶次：`FTF = 0.402` | `BPFO = 3.572` | `BPFI = 5.430` | `BSF = 2.322`
- **缺齿故障设定**：中间轴输入大齿轮 **`SS1.5-95` 单齿完全缺失**，理论冲击基频 = 中间轴转频 $f_{\text{mid}}$（`3.05 / 6.11 / 9.16 Hz`），在一级啮合频率 $f_{m1}$ 两侧形成 $f_{m1} \pm n f_{\text{mid}}$ 调制边频带。

### 一级行星齿轮箱（备忘，暂缓）
- **齿轮参数**（模数 $m = 1.0\text{ mm}$）：太阳轮 `SS1-28`（输入）、行星轮 `SS1-36`、固定齿圈 `SS1-100`、行星架输出，传动比 **$4.571$**。
- **支撑轴承**：太阳轮轴 `6900`、行星轮 `61800`、行星架输出轴 `ER-16K`。

## 5. Abaqus 显式动力学仿真方案（路线一 · 第一级齿轮副）

- **简化范围**：仅建第一级 `SS1.5-29` ↔ `SS1.5-95`（2D 平面应力 `CPS4R`，厚度 `15 mm`，中心距 `93.0 mm`），分别跑 **健康** 与 **`SS1.5-95` 单齿全缺** 两组算例；详见 `models/Abaqus第一级仿真模型示意.html`。
- **推荐工况与分析步**：`Dynamic, Explicit`，**30 Hz（1800 rpm，`VR3 = 188.5 rad/s`，前 `0.03 s` 用 Smooth Step 升速）**，从动轮施加等效阻力矩 `-10 N·m`，仿真时长 **`0.5 s`**（含 4~5 次缺齿冲击），**严禁开启 Mass Scaling**。
- **接触与网格**：`General Contact`（法向硬接触，切向 $\mu = 0.08$）；齿廓与齿根区加密至 `0.25 mm`，轮辐放粗至 `2.5 mm`。
- **弹性轴承支承（`ER-16K` 等效，统一 `mm-tonne-s-N-MPa` 单位制）**：
  - 材料 S45C：$E = 206000\text{ MPa}$，$\nu = 0.3$，$\rho = 7.85\times 10^{-9}\text{ tonne/mm}^3$；扭矩 `-10000 N·mm`
  - 内孔 `Kinematic Coupling` 至中心参考点 `RP1 / RP2`，X/Y 方向接弹簧-阻尼至大地（禁止刚性固支 `U1=U2=0`）
  - 径向刚度：$k_x = k_y = \mathbf{1\times 10^5\text{ N/mm}}$（即 $1\times 10^8\text{ N/m}$）
  - 阻尼（$\zeta = 0.05$）：输入侧 `RP1` $c_1 \approx \mathbf{0.7\text{ N}\cdot\text{s/mm}}$，中间轴 `RP2` $c_2 \approx \mathbf{1.5\text{ N}\cdot\text{s/mm}}$
- **虚拟传感器测点**：在 **`RP2`（优先，缺齿所在轴）** 与 `RP1` 输出 `History Output` 径向加速度 **`A1, A2`**（可同步输出弹簧支反力 `CTF1, CTF2`），等时间间隔采样 **`12800 Hz`**（$\Delta t = 7.8125\times 10^{-5}\text{ s}$），剔除前 `0.05 s` 启动瞬态后导出分析。
