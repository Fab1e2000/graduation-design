用一个最简单的例子（高频 50 Hz 共振 × 低频 5 Hz 周期敲击），看懂希尔伯特变换如何用勾股定理把高频消掉、把低频冲击扒出来！

核心魔法：复平面上的「勾股定理」 cos²θ + sin²θ = 1

0.00

0.00
希尔伯特变换只干一件事：把 cos 延迟 90° 变成 sin！
E(t) = √( x(t)² + x̂(t)² )
= √( E²cos²θ + E²sin²θ ) = E(t)
第 1~2 步：原信号（蓝）+ 延迟 90° 的希尔伯特信号（青）→ 算出红色包络线 消除正负抵消
动手观察：点「暂停扫描」后慢慢拖动上面的「时间游标 t」。你会发现蓝线 x(t) 和青线 x̂(t) 在不停一正一负交叉震荡，但左侧直角三角形的红色斜边长度 √(蓝² + 青²) 永远严丝合缝地贴在红色包络外轮廓上——高频震荡被 cos²+sin²=1 彻底消灭了！
对照：直接对原信号 x(t) 做普通 FFT 低频 5 Hz 处是空的！
因为原信号在 0 上下剧烈正负交替，正负半周在低频视角下互相抵消，全部能量都挤在高频共振区（fc 附近），低频敲击频率处几乎为 0。
第 3 步：对红色包络线 E(t) 做 FFT（包络谱） 精准抓出 5 Hz 真凶！
红线 E(t) 永远 ≥ 0、不再正负抵消，直接记录了“每次敲钟鼓起的大包”。对它做 FFT，敲击频率 fimpact 及其 2 倍、3 倍频立刻一柱擎天！
